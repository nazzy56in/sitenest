# SiteNest starter website

A simple responsive landing page for a ready-made website rental business.

## Publish with GitHub Pages or Cloudflare Pages

1. Upload `index.html` to the root of your GitHub repository.
2. Connect the repository to Cloudflare Pages.
3. Use the following build settings for a plain HTML site:
   - Framework preset: None
   - Build command: leave blank
   - Build output directory: `/` (or the repository root, as requested by the dashboard)
4. Deploy and test the public URL.

## Before launch

- In `index.html`, replace `91XXXXXXXXXX` with your WhatsApp number, digits only, including country code.
- Update the prices and service terms to match what you actually provide.
- Add your business email, legal name, privacy policy and rental terms before taking customer payments.
- Use customer-owned domains where possible; domain registration and renewals should be agreed separately.

This is a static demo site. It does not process payments or collect/store customer data.
